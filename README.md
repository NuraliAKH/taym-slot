# 🚀 Uzum Seller Slot Bot (Автобронирование и Мониторинг тайм-слотов)

Telegram-бот для автоматического перехвата (Auto-Snipe) и мониторинга освобождающихся тайм-слотов сдачи товара на склад Uzum Market (Fullfilment Markazi).

---

## 🌟 Основные возможности

1. 🎯 **Автоматический захват слота (Auto-Snipe)**:
   - Выбираете накладные, желаемые даты и диапазон времени (утро/день/вечер/любое).
   - Бот непрерывно опрашивает API Uzum Seller с защитой от банов.
   - Как только слот освобождается (отмена брони другим продавцом или новые квоты), бот **за миллисекунды отправляет запрос бронирования** и мгновенно закрепляет слот за вашими накладными.

2. 🔔 **Мониторинг и уведомления**:
   - Бот отслеживает свободные слоты на выбранные дни.
   - При обнаружении слота присылает сообщение в Telegram с интерактивной кнопкой **«⚡ Занять слот»** для мгновенного бронирования в 1 клик.

3. 🏬 **Мульти-магазины и мульти-накладные**:
   - Поддержка нескольких магазинов на одном аккаунте продавца.
   - Выбор одной или сразу нескольких накладных (групповая бронь слота).

4. ⚡ **Высокая скорость и отказоустойчивость**:
   - Асинхронный движок на `httpx` с постоянным Keep-Alive соединением.
   - Умный джиттер запросов и авто-переподключение.

## 🛠️ Установка и запуск

### 1. Требования
- Python 3.10+ (протестировано на Python 3.13)
- Установленный `pip`

### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 3. Настройка конфигурации (`.env`)
Откройте файл `.env` и укажите ваш токен Telegram-бота:
```env
BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz
UZUM_BASE_API_URL=https://api-seller.uzum.uz
DEFAULT_POLL_INTERVAL=2.0
DB_PATH=uzum_bot.db
```

> **Как создать бота в Telegram**:
> 1. Напишите [@BotFather](https://t.me/BotFather) команду `/newbot`.
> 2. Задайте имя и username для бота.
> 3. Скопируйте полученный HTTP API Token в `.env` (`BOT_TOKEN=...`).

### 4. Запуск бота
```bash
python bot.py
```

## 🔑 Как получить токен Uzum Seller

1. Откройте личный кабинет [seller.uzum.uz](https://seller.uzum.uz) в браузере Google Chrome / Яндекс.Браузер.
2. Нажмите клавишу **F12** (или `Ctrl + Shift + I`) для открытия DevTools.
3. Перейдите во вкладку **Сеть (Network)** -> фильтр **Fetch/XHR**.
4. Обновите страницу или перейдите в раздел накладных.
5. Найдите любой запрос к `api-seller.uzum.uz` (например `check_token` или `invoice`).
6. В разделе **Request Headers** найдите `Authorization: Bearer <TOKEN>` или в теле запроса `check_token` скопируйте параметр `token`.
7. Запустите Telegram-бота (`/start`) и отправьте ему этот токен.

## 📱 Как пользоваться ботом

1. **/start** — Первоначальный вход и проверка токена.
2. **📋 Накладные** — Просмотр актуального списка ваших накладных и их слотов.
3. **🎯 Поймать слот (Автобронь)**:
   - Шаг 1: Выберите накладные (отметьте галочками).
   - Шаг 2: Выберите даты доставки (сегодня, завтра, конкретные дни или любой день).
   - Шаг 3: Выберите желаемое время (утро / день / вечер / 24ч).
   - Задача запустится в фоне. Когда появится слот, бот автоматически займет его и пришлет отчет.
4. **🔔 Уведомить о слоте**:
   - Аналогичный выбор параметров, но бот не займет слот автоматически, а сразу пришлет алерт с кнопкой ручной брони.
5. **⚡ Активные задачи** — Просмотр и остановка запущенных фоновых процессов.
6. **⚙️ Магазин и Настройки** — Переключение между магазинами и обновление токена.
